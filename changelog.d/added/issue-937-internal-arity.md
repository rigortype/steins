- **A call to an internal function, an engine class's method or constructor, or a callback handed to an invoking builtin is now judged for argument count, from the analysing PHP's own reflection.** `strlen()`, `intdiv(1)`, `max()`, `var_dump()`, `$d->format()` on a `DateTime` and `new DateTimeZone()` report `call.too-few-arguments`; `strlen("a", "b")` and `session_id(1, 2)`, a non-variadic internal function given too many, report `call.too-many-arguments` (registered since ADR-0049 and silent until now; no id is left registered-not-yet-emitted); `strlen(str: "a")` reports `call.unknown-named-argument`; and `array_map(fn($a, $b) => 1, [1])`, `array_filter([1], fn($a, $b) => 1)`, `call_user_func(fn($a, $b) => 1, 1)`, `usort`/`uasort`/`uksort` over two or more elements, `array_walk` and `array_reduce` over a non-empty literal array, and a first-class callable or proven string naming a function there report `call.too-few-arguments` at the callback (#937). Everything reads the reflection of the PHP that runs the analysis, so it is silent under `--no-php`, on a skewed PHP, or beside a runtime-redefinition extension, and `rand(1)` stays silent because reflection reports zero required parameters. Left silent on purpose: an unknown named argument to a variadic (`call_user_func` forwards named extras), a surplus argument to an engine method (reflection carries no variadic flag), `preg_replace_callback` (it runs only on a match), `[$o, 'm']` and `'A::m'` callbacks, and a callback that may never run (an empty or unproven array, `array_filter` with a non-literal mode). See ADR-0049's 2026-10-14 amendment.
