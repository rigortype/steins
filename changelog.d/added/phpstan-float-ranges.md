- **PHPStan's float ranges are now supported: `float<0, 1.5>`, `float<min, 100.0>` and the named `positive-float`, `negative-float`, `non-negative-float`, `non-positive-float` and `finite-float`.** Bounds are inclusive int or float literals or `min`/`max`, `positive-float` and `negative-float` are strict, an int is judged by the float it widens to, and `NAN` is in no range (as in PHPStan). A call or return that provably violates one is now a `phpdoc.param-mismatch` / `phpdoc.return-mismatch` finding, and the five named spellings no longer report `phpdoc.unknown-vocabulary`; `float<lo, hi>` was previously never checked. Findings can appear where a proven float or int argument falls outside a declared range, and `phpdoc.unknown-vocabulary` findings on the five names disappear.
