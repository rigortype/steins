- **New finding `return.compile-fatal` reports the three `return` statements PHP refuses at compile time, on the default surface.** A value returned from a `: void` function, method, closure or arrow function (`return null;` included), any `return` in a `: never` one, and a bare `return;` under any other written return type (`int`, `?int`, `mixed`, `array`, `static`, `self`, `null`, `false`, a class) are fatals before the file runs, so the finding holds in dead code too and quotes PHP's own sentence. A `return null;` under `: int` compiles and stays `type.return-mismatch`; a constructor, a generator body, `?void` and `int|void`, and a property hook body are left alone. New findings appear only where a file PHP cannot load was silent before; none appeared on the ten public packages. See ADR-0078's 2026-10-11 amendment.
