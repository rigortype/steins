- **An argument or return whose docblock-claimed value is rejected by the native type in every member now reports `phpdoc.maybe-argument-mismatch` / `phpdoc.maybe-return-mismatch` under `--profile strict`, where it was silent.** The default profile is unchanged, and a proven (`Verified`) value that fails every member keeps its definite id, while a `Verified` abstract `string` into `?int` stays silent. New findings can appear for a `@param 'a'|'b'` on a `mixed` parameter passed to an `int` parameter, for an `if`/`else` or ternary join of literals none of which the callee accepts, for a preg-seeded capture group (`takes_int($m[1])` on a literal `(x)` group), and for an `@param string` on `mixed` passed to `int` in a strict file.
  - **The message names every member (`its "a" and "b" arms raise a TypeError`) or says `its every arm raises a TypeError` for an abstract type.** The ids are strict-floored and sit in the fp-gate's tripwire bucket.
