- **`steins effect-diff` runs the whole-project effect and throw fixpoints once per run instead of once per file.** The fixpoints do not depend on which file is being summarized, so a run over a directory repeated the same work for every file in it; each file's summaries are now read off one shared result. The baseline file and the diff it prints are byte-identical to before, and no finding appears or disappears. The library gains `effect_summaries_project_files` for callers that summarize many files of one project.
