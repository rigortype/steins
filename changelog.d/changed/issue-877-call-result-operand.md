- **A call whose declared return holds no object no longer leaves the site that uses it unbounded.** An operand that is a call (`'x' . strlen($s)`, `foreach (explode(',', $s) as $p)`, `explode(',', $s)[0]`, `count(explode(',', $s))`, `new \RuntimeException(sprintf('%s!', $s))` in a coercive file, `'x' . $e->getLine()`) was read as possibly an object whose `__toString`, iteration or offset access runs your code, so the body read `…?`. It is now read off the callee's declared return: a builtin's catalogued return (`int<1, max>|0`, `uppercase-string`, `non-empty-string|false`, `list<string>`), a project function's or method's native return hint (a method on a bound receiver too, since PHP refuses an override whose return type is not covariant), and a final `Throwable` accessor over a typed property (`getFile()`, `getLine()`, `getTraceAsString()`). An array that may hold an object is not an object, so an iteration or an offset read of it runs nothing. Still unproven: a `mixed`, class (`GMP`), `iterable`, `static` or absent return, a function PHP may bind to another one (a namespaced function that shadows the builtin, a conditional declaration), a private or protected method the calling scope cannot reach (the engine hands it to `__call`), `getMessage()` and `getCode()` (an untyped property a subclass may fill with an object), any engine method on a bound receiver other than those final accessors (a tentative return type may be overridden), arithmetic, and a local assigned from a call. Bodies can lose their `…?` and become exhaustive, `effects-envelope` can plan more tags, and `throw.maybe-undeclared` at `strict` and `user-code-reach`, `operator-to-string`, `operator-iteration` and `operator-array-access` kinds disappear from `annotate --format json` and the effect baseline. On the ten public corpus packages (28,847 functions) 2,317 functions lose a gap kind and none gains one, 83 become exhaustive and none stops being so, `effect-diff` reports 63 `coverage-completed` events, `transform effects-envelope` plans 17 more edits (14 `@phpstan-impure nondet.time`, 3 `@phpstan-all-methods-pure`), `throws-envelope` and `loop-to-array-map` are unchanged, and `throw.maybe-undeclared` at `strict` loses 283 findings (composer 120, phpunit 74, console 62, process 13, Carbon 5, guzzle 5, monolog 4).
