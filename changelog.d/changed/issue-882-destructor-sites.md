- **A dropped value that may run `__destruct` is now a coverage gap, so a body that drops one reads `…?` and the strict floor reports it.** The gap kind `destructor` (reserved by the schema-24 gate) is recorded at the places a value is released: `unset($v)`, an assignment over `$v`, the end of the body, and a `new` that dies in the statement, receiver or argument position that holds it. The value is a local whose first write is `new C` (an anonymous class too), or a parameter read by its native class hint even where the body writes it; a `new` that is assigned, returned, stored, yielded, captured or put in an array literal is no site. It counts when the class declares `__destruct` or imports a trait that does or cannot be read, when a subclass in the project or an anonymous class whose body runs one that extends it may, and when a typed property on its chain, or on a trait it imports, names a class that does (the entry below moves the trait and anonymous-class readings from a proxy to what the body declares, and counts a class no file declares); no drop is an edge, because a constructor that stores `$this`, a self-reference or a throwing constructor each move or cancel the destructor. Not covered, so still silent: an untyped value, an array, a property that is untyped or hinted `array`, `mixed`, `object` or `iterable`, a closure's captures, a suspended generator's or fiber's `finally`, a subclass's own properties through its parent's type, `array_splice`, and code outside a function-like body (the entry for issue 1003 below widens the subjects: any write that stores a `new`, a `new` an expression consumes, and a typed property's overwrite or `unset`). Findings can appear and nothing disappears: `throw.maybe-undeclared` and `effect.maybe-envelope-exceeded` at `strict` gain the kind, bodies that were exhaustive become `…?`, `effect-diff` reports them as `coverage-narrowed`, and `transform effects-envelope` refuses the functions it tagged. On the ten public corpus packages 85 of 28,846 functions stop being exhaustive in the effect lane (91 in the throw lane) and none becomes so, `effect-diff` reports 85 `coverage-narrowed` events, `transform effects-envelope` plans 15 fewer edits (740 to 725: phpunit 10, composer 2, monolog, guzzle and console 1 each), `throws-envelope` and `loop-to-array-map` are unchanged, and `throw.maybe-undeclared` at `strict` gains 126 findings (phpunit 107, console 8, composer 5, Carbon 4, guzzle 2) while 248 more name the new kind.
