- **A dropped value that may run `__destruct` is now a coverage gap, so a body that drops one reads `…?` and the strict floor reports it.** The gap kind `destructor` (reserved by the schema-24 gate) is recorded at the places a value is released: `unset($v)`, an assignment over `$v`, the end of the body, and a `new` that dies in the statement, receiver or argument position that holds it. The value is a local whose first write is `new C` (an anonymous class too), or a parameter read by its native class hint even where the body writes it; a `new` that is assigned, returned, stored, yielded, captured or put in an array literal is no site. It counts when the class declares `__destruct` or imports a trait (whose body is not lowered), when a subclass in the project or an anonymous class that extends it may, and when a typed property on its chain names a class that does; no drop is an edge, because a constructor that stores `$this`, a self-reference or a throwing constructor each move or cancel the destructor. Not covered, so still silent: an untyped value, an array, a property that is untyped or hinted `array`, `mixed`, `object` or `iterable`, a closure's captures, a suspended generator's or fiber's `finally`, a subclass's own properties through its parent's type, `array_splice`, and code outside a function-like body. Findings can appear and nothing disappears: `throw.maybe-undeclared` and `effect.maybe-envelope-exceeded` at `strict` gain the kind, bodies that were exhaustive become `…?`, `effect-diff` reports them as `coverage-narrowed`, and `transform effects-envelope` refuses the functions it tagged. On the ten public corpus packages the gate marks 3,823 sites, 81 of 28,846 functions stop being exhaustive in the effect lane (86 in the throw lane) and none becomes so, `effect-diff` reports 81 `coverage-narrowed` events, `transform effects-envelope` plans 15 fewer edits (740 to 725: phpunit 10, composer 2, monolog, guzzle and console 1 each), `throws-envelope` and `loop-to-array-map` are unchanged, and `throw.maybe-undeclared` at `strict` gains 117 findings (phpunit 99, console 8, composer 4, Carbon 4, guzzle 2) while 248 more name the new kind.
