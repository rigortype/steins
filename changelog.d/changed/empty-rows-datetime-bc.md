- **`bcceil`, `bcfloor`, `bcround`, the readers and setters of a built `DateTime` or `DateTimeImmutable`, `DateTimeZone`'s constructor, `getName` and `getOffset`, and `DateTime::createFromTimestamp` now carry an empty effect row, so a pure function over them can be exhaustive (#1000).** Before, each was the honest `no-effect-row` gap, which cost precision only. A throw is still reported by the throw table, which these rows do not change. A method call on a `new` receiver with a literal `string` argument stays blind in coercive code and is exhaustive under `strict_types`. On the public corpus one strict-profile `throw.maybe-undeclared` finding in `cakephp/chronos` disappears (a false positive); no finding appears.
