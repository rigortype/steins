- **`setlocale` names the environment cell it reads for `''` and `null`, `global.read.setting.env`, so an envelope can admit that read beside the locale write (#1020).** Before, the row carried the coarse `global.read`, which a `global.write.setting.locale` envelope paired with `global.read.setting.env` did not admit, so `setlocale(LC_ALL, '')` was refused there. A `global.read` or `global` envelope admits it as before, and a call with a written non-empty locale is unchanged. A finding disappears only where an envelope names the env cell and the write; `effect-diff` reports the functions that call `setlocale` with `''` or `null`, whose label now reads `global.read.setting.env`.
