- **The playground's PHP engine is now PHP 8.5.13 built by php-wasm-builder 1.0, in place of php-wasm 0.1.0's PHP 8.5.2, and it carries bcmath, calendar, ctype, dom, exif, fileinfo, filter, libxml, mbstring, PDO with pdo_sqlite, phar, session, SimpleXML, sqlite3, tokenizer, the XML readers and writers, and zlib.** With the engine on, a call into one of these extensions is no longer reported as `call.undefined-function`: before, `mb_strlen()` and `dom_import_simplexml()`, among others, were, because the old engine lacked their extensions. A call into iconv, openssl, gd, zip, sodium or intl still is. The engine is still 32-bit, so the folded subset, the refused names and the declined curated rows are unchanged. The native `steins check` is unaffected.
  - The engine answers a batch of questions in one run of the sidecar runner over NDJSON, as the native child does, and each batch starts from fresh PHP state; a fatal costs only the request that raised it.
  - The download is about 4.5 MB compressed, and the page no longer patches `document` into the engine's Worker.
  - Building the engine (`apps/playground/build.sh`) now needs Docker with buildx.
