- **Floats in dumped types and diagnostics are spelled as PHP and PHPStan spell them.** A float that PHP prints in exponent form now reads that way instead of as a long decimal: `9223372036854775808` (an int literal past `PHP_INT_MAX`) dumps `9.223372036854776E+18`, not `9223372036854775808.0`; `1e20` is `1.0E+20`, `PHP_FLOAT_MAX` is `1.7976931348623157E+308`, `1e-5` is `1.0E-5`, and an infinity is `INF`/`-INF`. Fixed notation is kept from `0.0001` up to `1.0E+16` exactly as before. A declared float range now dumps as its interval, `positive-float` as `float<5.0E-324, max>` and `float<0, 1>` as `float<0.0, 1.0>`, and `float<0, 1>|float<1, 2>` is merged to `float<0.0, 2.0>`. The change is to text: `debug.type` dumps, `annotate` output and messages that print a float read differently, so a baseline keyed on a message containing such a float needs regenerating.
