- **Appending to or writing into one array a few thousand times in straight-line code no longer takes minutes, and an array built past 256 keys that way is summarized instead of listed.** Each `$a[] = v` and `$a['k'] = v` on an array whose keys the analysis had watched being built rebuilt the whole key list, and the rebuild itself was quadratic, so the cost of N such statements grew with N cubed: 3,000 appends took about 10 seconds and a generated file with tens of thousands never finished. The lookups inside the rebuild are now linear or logarithmic, and the 256-key width bound (ADR-0062 A-G6), until now enforced only for array literals, applies to every array the analysis builds, so past 256 keys it keeps the key type and the value type but not the key list. A proven `offset.undeclared` finding on an array built past 256 keys by appends or writes can therefore disappear: after 300 appends of `$a[] = …`, reading `$a[300]` was reported and now is not, while reading `$a['k']` is still reported because the keys are known to be integers. The public corpora report the same findings as before.
