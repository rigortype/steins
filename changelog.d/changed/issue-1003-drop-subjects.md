- **The `destructor` gap now covers a `new` that reaches a local through any write, a `new` that an expression consumes, and a write to or `unset` of a typed property, so a body that drops one in those shapes reads `…?` and the strict floor reports it.** A local is a subject by any plain write that stores a `new` (a ternary, `?:`, `??` or `match` arm, a `clone`, a nested assignment), not only its first (`$x = null; $x = new D;`), and a by-value parameter the body overwrites with one is a subject whatever its hint; a write drops nothing while no earlier write could have stored an object. A `new` is a temporary wherever the expression consumes it (`clone new D()` drops twice, `(new D())->p`, `echo new D()`, `new D() instanceof D`, a cast, a condition, a `foreach` or `match` subject), not only as a statement, a receiver or an argument. A plain write to `$this->p`, `self::$p`, `static::$p`, `parent::$p` or `C::$p` and an `unset($this->p)` release what the property held and are a gap when its declared hint (read as written: `array|D`, `?self`, a trait's property by name) names a class that reaches a destructor, so the close-and-reset pattern and a destructor that throws at the assignment are covered; a readonly property (a `readonly class`'s too), a hooked one and a parent's `private` one written from a subclass are not, a property only a subclass declares is read in the subclass (`static::$p`, an abstract base's `$this->p`), and a constructor's first write of its own uninitialized (or `null`) property drops nothing. Not covered, so still silent: an untyped property and one hinted `array`, `mixed`, `object` or `iterable` (what they hold is whatever the class stores into them), another object's property, `??=`, and an explicit second call of `__construct`. Findings can appear and nothing disappears: on the ten public corpus packages the first two groups move nothing and the property writes add 34 `throw.maybe-undeclared` at `strict` (phpunit 21, guzzle 5, Carbon 4, monolog 2, console 2; 16 are callers of one lazy-singleton write) and reword 12 whose callee gained the kind, no function changes exhaustiveness there (a method that writes a property is already `…?` for `state-construct`; a constructor's second write, a write in a loop or after a use of `$this` flips it, and none of the packages has one), `effect-diff` reports no event, and the three `transform` dry-runs plan the same edits.
