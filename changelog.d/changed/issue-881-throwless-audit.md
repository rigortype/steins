- **Twelve builtins no longer read as raising nothing: a body that calls `in_array`, `array_search`, `array_keys` with a search value, `array_unique`, `sort`, `rsort`, `asort`, `arsort`, `array_replace_recursive`, `array_walk_recursive`, `date_create` or `date_create_immutable` now has `Error` in its throw set.** A re-audit of the throwless table against php-src found that an `array` parameter admits an array that contains itself by reference, and comparing two of them (or walking one with `array_replace_recursive` or `array_walk_recursive`) is an `Error`, and that `date_create` and `date_create_immutable` raise an `Error` for a user subclass of `DateTimeZone` that never ran its parent's constructor. `Error` is an unchecked class, so no `check` finding, effect baseline entry or transform plan changes on the public corpora; what changes is the throw set that `annotate` prints (477 body margins in 227 files of the ten public corpus packages gain `Error`, and nothing else moves). `array_keys($a)` with one argument compares nothing and still raises nothing, and a call whose arguments are all literals is still read as raising nothing, so the dead-statement check is unchanged.
