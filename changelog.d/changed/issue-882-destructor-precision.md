- **A trait user and an anonymous class now count for what their body declares, and a class no file declares counts as one that may declare a destructor, so the `destructor` gap moves: fewer through proxies, more through names a checkout lacks.** A class that imports a trait is a `destructor` source only when a trait it imports declares `__destruct`, aliases a method as one (`use T { bye as __destruct; }`), imports a trait that does, holds a typed property whose class does, or cannot be read (no file declares it, two do, a condition guards it, a literal `class_alias` names it); a clean trait leaves its users out. An anonymous class makes its parent and interfaces a source only when its own body declares a destructor or imports such a trait, where any anonymous subclass used to. A class no file declares and the engine does not, as a parent, a parameter or property hint or an imported trait, may declare one (the unclosed-chain rule every other gap kind reads): in a project with `vendor/` the names resolve and read as any class does, and in a checkout without it, PSR types and Symfony contracts count. A `new` of such a class is left to the unknown-class gap it records already. A trait's methods and properties are read by name and hint only; nothing of a trait body is analyzed. The generation schema moves to 25, so a cache another build wrote is rebuilt once. Findings can appear and disappear: on the ten public packages 607 and 1,117 drop sites go and 2,774 are added, `throw.maybe-undeclared` at `strict` goes from 8,122 to 8,077 (anonymous classes -92 in phpunit and console, traits -14, unseen names +61 in composer, guzzle, phpunit, monolog and console), 70 functions stop being effect-exhaustive and 58 become so (5,896 to 5,884 of 28,846), `effect-diff` reports 70 `coverage-narrowed` and 58 `coverage-completed` events, `transform effects-envelope` plans the same 730 edits in different places (phpunit 7 more, composer, guzzle and console 2 fewer each, flysystem 1), and `throws-envelope` and `loop-to-array-map` are unchanged.
