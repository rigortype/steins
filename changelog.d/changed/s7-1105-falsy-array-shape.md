A nested guard that contradicts the empty array (`if ($row)`, `count($row) > 0`, `isset($row['x'])`) drops the claim, so the dead region stays silent. New `offset.undeclared` findings can appear in strict profiles; a nullable base (`?array`) binds nothing, a literal the analysis proved (`$row = []`) keeps its `offset.missing` with the sidecar, and `$row === []` is unchanged.
