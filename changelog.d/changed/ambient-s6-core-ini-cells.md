- **`ini_get`, `ini_set`, `ini_alter` and `ini_restore` with a literal option name now carry the read and write of the setting cell that owns the name, in place of the coarse `global.read` and `global.write`.** `ini_get('date.timezone')` is `global.read.setting.timezone` and `ini_get('include_path')` is `global.read.setting.ini`; `ini_set` and `ini_alter` return the old value, so `ini_set('precision', '3')` is both `global.read.setting.precision` and `global.write.setting.precision`, and `ini_restore` is the write alone. The names `serialize_precision`, `date.timezone`, the `iconv.*_encoding` entries, six `mbstring.*` entries (`language`, `detect_order`, `http_input`, `http_output`, `substitute_character`, `strict_detection`), `bcmath.scale`, `include_path` and `error_reporting` map to the precision, timezone, encoding and ini cells the same way. `default_charset`, `internal_encoding`, `input_encoding`, `output_encoding` and `mbstring.internal_encoding` stay on the coarse row, because rewriting one also resets the mb-regex encoding, which no cell holds yet. A name no cell owns, a name that is not a string literal, a spelling the engine does not find (the lookup is case-sensitive), an argument count that is not the function's own and a function passed as a callback keep the coarse row. `ini_alter` and `ini_restore` had no row and are now `global.write`, so a body that calls one is no longer a `no-effect-row` gap.
  - Seven labels join the registry with these rows (`global.read.setting.timezone`, `.encoding` and `.ini`, and the writes of `precision`, `timezone`, `encoding` and `ini`), all children of the coarse labels. An envelope that declares `global.read`, `global.write` or `global` admits them, with one change: an `ini_set` of a mapped name now carries a read as well, so an envelope that declares only `global.write` (or only the cell's write label) is exceeded by it, as the call's returned old value warrants. A label that was unknown is now known, so `effect.unknown-label` no longer fires on it, near-miss suggestions can offer it, and an interop docblock tag that names one binds as an envelope.
  - The value an `ini_set` or `ini_alter` of a mapped name stores is converted to a string first, so a value shown to be a float adds `global.read.setting.precision`, a value shown not to be one adds nothing, and any other value is the `value-dependent-read` coverage gap.
  - Findings and `annotate` margins that name the label read the cell's label where they read `global.read` or `global.write`; the locale gate is now `SettingReadGate`, which names the cell it decides, and no locale verdict moves.
