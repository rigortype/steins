- **`ini_get`, `ini_set`, `ini_alter` and `ini_restore` with a literal option name now carry the read or write of the setting cell that owns the name, in place of the coarse `global.read` and `global.write`.** `ini_set('precision', '3')` is `global.write.setting.precision`, `ini_get('date.timezone')` is `global.read.setting.timezone`, and `ini_get('include_path')` is `global.read.setting.ini`; the names `serialize_precision`, `default_charset`, `internal_encoding`, `input_encoding`, `output_encoding`, the `iconv.*_encoding` entries, seven `mbstring.*` entries, `bcmath.scale` and `error_reporting` map to the precision, encoding and ini cells the same way. Seven labels join the registry with these rows (`global.read.setting.timezone`, `.encoding` and `.ini`, and the writes of `precision`, `timezone`, `encoding` and `ini`), all children of the coarse labels, so an envelope that declares `global.read`, `global.write` or `global` admits them as before; an envelope that names a narrower label (`global.read.setting.locale`) does not admit another cell's. A name no cell owns, a name that is not a string literal, a spelling the engine does not find (the lookup is case-sensitive), an argument count that is not the function's own and a function passed as a callback keep the coarse row. `ini_alter` and `ini_restore` had no row and are now `global.write`, so a body that calls one is no longer a `no-effect-row` gap.
  - Findings and `annotate` margins that name the label read `global.read.setting.precision` where they read `global.read`; no finding appears or disappears except where a body held only an `ini_alter` or `ini_restore` call.
  - The locale gate is now `SettingReadGate`, which names the cell it decides; no locale verdict moves.
