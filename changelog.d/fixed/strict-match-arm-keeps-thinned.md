- **A strict `match` arm no longer turns a possibly-grade argument finding into a proven one.** The arm rebinding its subject dropped the mark that a guard's exit had thinned the subject's members, so `$k = $c ? 1 : 2; if ($y > 0 && time() > 0) return; match ($k) { 1, 2 => takes($k) }` reported `type.argument-mismatch` although PHP never reaches the call (#1090). **Findings can disappear:** that proven report is gone, and the strict profile reports `type.maybe-argument-mismatch` instead; this applies to a multi-label strict arm, and a strict arm with no exit before the `match`, or over an `@param 1|2` subject, still reports the proven mismatch.
