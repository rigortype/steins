- **A builtin call whose `string` parameter receives a float literal is no longer folded to a value computed at the default `precision`.** `strlen(1.5)` folded to `3`, which is wrong whenever the project sets `precision` differently (PHP gives `1` at `precision=1`). The call now keeps its declared return type; a float inside an array argument still folds, and the coercion stays unlabelled (ADR-0101 D4, §3.21). A finding that rested on such a folded value can disappear.
