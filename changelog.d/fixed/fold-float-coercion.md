- **A builtin call that turns a float literal into text is no longer folded to a value computed at the default `precision`.** `strlen(1.5)` folded to `3` and `sprintf('%s', 1.5)` to `'1.5'`, which is wrong whenever the project sets `precision` differently (PHP gives `1` and `'2'` at `precision=1`). The fold now refuses a float literal at a `string` parameter, in an array literal at an `array|string` parameter (`str_replace('x', 'y', [1.5])`) and at a printf `%s`; the call keeps its declared return type. `array_unique` and loose `in_array` over floats still fold, and the coercion stays unlabelled (ADR-0101 D4, §3.21). A finding that rested on such a folded value can disappear.
