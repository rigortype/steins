- **A call that supplies a destructuring assignment is checked like the same call on the right of `$t = …`.** `[$a, $b] = nope_fn();`, `[$a] = f();` with `f()` taking a required parameter, and `['k' => $x] = $obj->nope();` now report the undefined function, the too-few arguments and the undefined method, as their assignment spellings already did. Steins used to check the source of a destructuring assignment for its reads but not for the call itself. Extra positional arguments to a userland function stay silent, as PHP runs them clean.
  - **Findings can appear:** `call.undefined-function`, `call.undefined-method`, `call.too-few-arguments`, `call.unknown-named-argument`, `call.inaccessible-method` and the other call findings on the call of a destructuring assignment.
