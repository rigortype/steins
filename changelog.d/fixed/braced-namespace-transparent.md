- **Declarations inside a braced `namespace A { … }` are now read as unconditional, as they already were for `namespace A;`, so a call to a `: never` function inside such a file ends its path and no longer produces a false `call.on-null` on the code after it.** The braced body was treated as a conditional scope, which made the never-returning veto decline and left the successor live. Findings can disappear in braced-namespace files (the spurious `call.on-null` and any other finding that only followed the dead path), and the lanes that decline on a conditional declaration now reach braced-namespace declarations.
  - **A bare `{ … }` at file level is read the same way.** PHP hoists the functions and classes it declares, as it does for a `namespace` body, so a declaration in such a block is now unconditional too, and a `define()` directly in it counts as unconditional.
