- **The right operand of `&&` and `||`, and each arm of a ternary, now see the declared-type narrowing the left operand or the condition proves, as an `if` body already did, so `if ($n !== null && method_exists($n, 'gone')) { return $n->gone(); }` over a class without `gone` no longer reports `call.undefined-method`.** Past `$n !== null` the operand now reads `$n`'s declared arms without `null` (and past `instanceof`, a truthiness test, `!== v`, an enum-case identity or an array-key presence test, the arms those exclude), so a member guard over the remaining classes folds and the guarded body is dead. Findings can disappear inside code such a guard proves unreachable; a guard on a method the class does have keeps its body live and its findings.
  - **A ternary's value is sharper, so findings can also appear.** `$s !== null ? $s : 'c'` over `@param 'a'|'b'|null $s` is now `'a'|'b'|'c'`, and `isset($a['k']) ? $a : […]` over an optional or nullable shape now carries the shape the guard proved. A read of a key that shape cannot hold can now report `offset.undeclared` (strict) where it reported nothing or `offset.maybe-missing` before, and a narrower value can surface a type finding further on.
