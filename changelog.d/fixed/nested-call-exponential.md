- **A call nested many levels deep no longer stalls the run.** Steins worked out the value of each argument once for every rule that read it, and each of those did the same for the argument's own argument, so the cost of `strlen(strlen(…))` tripled with every level of nesting: 18 levels did not finish in a minute. Nested project-function calls doubled per level, and a nested method call, static call or `new` doubled per level while the file was being read. Each argument's value is now worked out once, and the same statement finishes in a twentieth of a second at 30 levels and in a few seconds at 200. Findings do not change: the ten public corpus packages report the same findings, at `strict` and at `default`.
