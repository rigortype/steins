- **An existence guard now discharges what it guards wherever it is written: `defined()`, `class_exists()` and `function_exists()` in a ternary in `return`, `echo`, an argument or an assignment, as the left side of `&&` or `||`, or as a `switch (true)` case; `extension_loaded()`, which was not recognised at all; and `method_exists()` and `is_callable([$o, 'm'])` on a parameter whose declared type has no such method.** `return defined('C') ? C : null;`, `class_exists('Foo') && new Foo();`, `if (class_exists('Foo') && Foo::X > 1) {}`, `switch (true) { case defined('C'): return C; }` and `if (extension_loaded('redis')) { $r = new Redis(); }` each reported `constant.undefined` or `class.undefined` on a line PHP never runs, because the guard is false on this PHP. Only `defined()` and `class_exists()` as an `if` condition were understood before.
  - **Findings can disappear in code a guard proves unreachable.** A reference outside any guard, on the guard's other side (`defined('C') ? 1 : C`, `class_exists('Foo') || new Foo()`), or inside the guard of a symbol that exists still reports.
  - `extension_loaded('name')` is answered from the extensions of the PHP that runs the analysis, case-insensitively, so `if (extension_loaded('redis')) { … }` is dead code where `redis` is not loaded and the `else` of `if (extension_loaded('json'))` is dead where it is. It stays undecided under `--no-php`, and wherever the project calls `dl()`; `dl()` leaves only `extension_loaded()` undecided and silences no other finding.
  - `method_exists($n, 'go')` and `is_callable([$n, 'go'])` over a declared type fold to false when every narrowed, native-typed arm of the type provably lacks `go`, so the guarded body is dead where the declared-receiver finding would have reported inside it. An arm that may have `go` leaves the guard undecided. `property_exists($n, 'p')` guards `$n->p` for `property.undefined` and `property.maybe-undefined` for that variable until it is reassigned: it is true for a dynamic property too, so it says nothing of other receivers of the class.
  - A `switch (true)` whose cases are calls or comparisons is now read as the `if`/`elseif`/`else` chain it is, and its last case may run off its end without a `break`. A `default:` that shares a body with case labels before a later case is not the `else`; such a `switch` stays unstructured, the by-value `switch` too, so **findings can appear** in a shared default body that the by-value reading used to hide.
  - **Findings can appear:** `class_exists()` of a class declared under a condition (`if (PHP_VERSION_ID < 80000) { class Polyfill {} }`), or of a project class with `$autoload` other than `true` (`class_exists('Later', false)`), is undecided, so the `else` that says it is missing is live and reports what it holds.
