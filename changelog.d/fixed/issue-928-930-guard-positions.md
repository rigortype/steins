- **An existence guard now discharges what it guards wherever it is written: `defined()`, `class_exists()` and `function_exists()` in a ternary in `return`, `echo`, an argument or an assignment, as the left side of `&&` or `||`, or as a `switch (true)` case; `extension_loaded()`, which was not recognised at all; and `method_exists()`, `is_callable([$o, 'm'])` and `property_exists()` on a parameter whose class comes from its declared type.** `return defined('C') ? C : null;`, `class_exists('Foo') && new Foo();`, `if (class_exists('Foo') && Foo::X > 1) {}`, `switch (true) { case defined('C'): return C; }`, `if (extension_loaded('redis')) { $r = new Redis(); }` and `function f(N $n) { if (method_exists($n, 'go')) { $n->go(); } }` each reported `constant.undefined`, `class.undefined`, `call.undefined-method` or `property.undefined` on a line PHP never runs, because the guard is false on this PHP. Only `defined()` and `class_exists()` as an `if` condition, and `method_exists()` on a variable bound by `new`, were understood before.
  - **Findings only disappear.** A reference outside any guard, on the guard's other side (`defined('C') ? 1 : C`, `class_exists('Foo') || new Foo()`), or inside the guard of a symbol that exists still reports.
  - `extension_loaded('name')` is answered from the extensions of the PHP that runs the analysis, case-insensitively, so `if (extension_loaded('redis')) { … }` is dead code where `redis` is not loaded and the `else` of `if (extension_loaded('json'))` is dead where it is. It stays undecided under `--no-php`, and wherever the project calls `dl()`, which is now a dam site: an extension loaded at run time brings classes, functions and constants Steins never saw, so the existence findings go quiet for such a project.
  - A `switch (true)` whose cases are calls or comparisons is now read as the `if`/`elseif`/`else` chain it is, so the findings inside its cases are judged as an `if`'s are. Its last case may now run off its end without a `break`.
  - `property_exists($o, 'p')` guards `$o->p` for `property.undefined` and `property.maybe-undefined`, and a vouch on a union-typed parameter covers every class of the union.
