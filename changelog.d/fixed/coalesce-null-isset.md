- **`($a['k'] ?? null) !== null` now narrows the way `isset($a['k'])` does.** Comparing a null-defaulted coalesce with `null`, in either operand order and with either `===` or `!==`, lowers to `isset`, so an optional key read after the guard is no longer reported as possibly missing and a null-stripped slot is no longer left nullable; a default other than `null` still proves nothing. Findings can only disappear.
