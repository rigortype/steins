- **A name both sides of an `if` rewrote through a by-reference call, a destructuring or a loop is no longer handed back as its pre-test value after the join.** Findings can appear: a later test of the name is judged on the value the sides left, so a branch the old hand-back pruned (`if ($s !== "abc") { return 1; }` after both sides called `setx($s)`) is now reported when its code is a proven error (#1110).
