- **A loose `switch` now narrows an int or bool subject inside each case.** `switch ($k) { case 1: … }` over an `int` binds `$k` to the label set (`case 2: case 3:` binds `2|3`), so a guard on `$k` in the case body is decided and a `call.on-null` that depended on the untaken branch no longer fires; a `?int` keeps `null` under a `case 0` and a `?bool` under a `case false`, as PHP does, and string or float subjects and string or mixed labels stay unnarrowed. Findings can also appear: a case body that passes the narrowed subject somewhere it cannot go (`function takes(string $s)` called as `takes($k)` inside `case 1:` under `strict_types`) now reports `type.argument-mismatch`.
