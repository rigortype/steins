- **A property created by passing it as an argument, binding it with `&`, or naming it in a destructure pattern is no longer reported as an undefined property when it is read later.** `byref($o->p); $x = $o->p;`, `settype($o->p, 'int')`, `preg_match($re, $s, $o->p)`, `$r = &$o->p`, `[$o->p] = $xs`, `['k' => $o->p] = $xs`, `list($o->p) = $xs`, `foreach ($xs as [$o->p])` and `$o->p[] = 1` all create the property in PHP, but only plain assignments, `++`/`--` and `foreach` targets counted as writes, so the following read produced a false `property.undefined`. Every argument counts as a possible write, since the callee's by-reference parameters are not known here, so a property name that is only ever passed to a function by value is also no longer reported when read.
