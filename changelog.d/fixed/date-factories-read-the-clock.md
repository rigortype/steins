- **`date_create()`, `date_create_immutable()`, `date_create_from_format()`, `date_create_immutable_from_format()`, `DateTime::createFromFormat()` and `DateTimeImmutable::createFromFormat()` now carry `nondet.time`, as `new DateTime()` does, so `effect.envelope-exceeded` can fire where it used to stay silent.** A `@pure` or `#[\Steins\Pure]` function that calls one now reports `nondet.time` at the call, and a body that calls one reads `nondet.time` where it read `…?` — **a green `--profile contracts` can turn red** where such an envelope holds one of these calls. The row is argument-blind, like `date()`'s: a string with no absolute time reads the clock, a format fills every field it leaves out from the current time, and a string naming no zone reads the ambient one, so `createFromFormat('!Y-m-d', $s)` is `nondet.time` too. A subclass that does not override `createFromFormat()` reaches the same row, through `parent::createFromFormat()` or `Sub::createFromFormat()`, and `steins transform effects-envelope` can write `@phpstan-impure nondet.time` over such a body.
  - `DateTime::createFromImmutable()`, `DateTimeImmutable::createFromMutable()` and `createFromInterface()` copy an existing value, and are now catalogued pure.
