- **A non-empty list now always holds key 0, so filling an empty list and reading `$xs[0]` after the `if` no longer reports a strict-profile `offset.maybe-missing`.** `if (empty($xs)) { $xs[] = 'd'; } return $xs[0];` over `list<string>`, and the same with `!$xs`, `$xs === []`, `$xs = ['d']`, or a literal assigned on one path to a declared `non-empty-list<T>`, joined the two paths into `non-empty-list{0?: string, ...<string>}` and reported the read; key 0 is now required wherever a shape is both a list and non-empty. Findings can only disappear: a list that may still be empty after the join, such as `list<string>` assigned `['d']` on one path only, keeps reporting.
