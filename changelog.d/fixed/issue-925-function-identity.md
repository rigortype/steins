- **Two functions of one name in different namespaces of one file are no longer mistaken for each other, so `Two\make()` is no longer checked against `One\make()`'s return type.** A file that declares several namespaces (the shape of a test suite that puts each case in its own braced `namespace`) answered every lookup of a function's declaration with the first function of that simple name in the file, so `Two\foo(): string` returning `"x"` was reported as `type.return-mismatch` against `One\foo(): int`, and a `@param` or native parameter type of the first function seeded the body of the second. A function is now identified by its namespaced name, in the braced and in the unbraced spelling.
  - **What was wrong, by lane.** The return check (`type.return-mismatch`, and the `@return` docblock check), the native and `@param` parameter seeds a body starts from, and the `@template` names that shadow a class inside a function body all read the first declaration of the simple name. So did the call-result descent, which declined outright when two scopes shared a name, and `type.return-missing`'s never-returning veto, which let a `: never` function in one namespace silence a missing return after a call to the same-named function of another.
  - **Findings can appear and disappear, only in files that declare a function name more than once across namespaces.** A mismatch the other namespace's declaration used to hide is now reported (`Two\foo(): int` returning `"x"` beside `One\foo(): string`), a value a call returns to its caller is proven again where the descent used to decline, and `type.return-missing` is reported for a function whose same-named sibling in another namespace is `: never`. On the ten public packages nothing changes, because none declares one function name in two namespaces of a file.
  - **`steins annotate`'s `@return` repair reads the right body.** `phpdoc-honesty` scanned the returns of the last same-named function in the file for every one of them, so it could rewrite the honest `@return` of one namespace's function to the other's returns; each function now scans its own, and a function name declared twice in one namespace (a conditional redeclaration) is not judged at all.
