- **`call.too-few-arguments` now fires through a closure, an arrow function, a first-class callable and a string callee.** A call such as `$adder = fn(int $a, int $b) => 0; $adder(1)`, `(function (int $a, int $b) {})(1)`, `$f = add(...); $f(1)`, `add(...)(1)` or `$f = 'add'; $f(1)` is the same ArgumentCountError as a direct call and is reported under the same rules (variadics, defaults, named arguments and unpacking stay silent). A string callee is read as a global function name, never a namespaced one; a value that is not one proven callable, an `__invoke` object, an array callable and `Closure::fromCallable` stay silent. New findings can appear on code that already ran into the error.
