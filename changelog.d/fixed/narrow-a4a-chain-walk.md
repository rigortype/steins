- **A declared interface receiver no longer reports `call.undefined-method` (or `phpdoc.undefined-method`) for a method one of its implementors inherits from a class outside the interface's hierarchy, or answers through an inherited `__call`.** The declared-receiver lane judged each implementor by its own body, so `A $x; $x->m()` reported `A::m()` when the implementor extended a class that declared `m()` or `__call`, and PHP ran the call. Each descendant is now judged by its whole parent chain, as the exact-receiver lane judges a class, and the property lane judges descendants the same way. Findings can only disappear: the ones on an interface receiver whose implementor inherits the method, or a `__call`, from outside the interface's hierarchy, or whose implementor extends a class Steins cannot enumerate.
