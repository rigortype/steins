- **Assigning one variable's object to another (`$x = $y`) now forgets what was known about `$x`'s old value, so a stored `method_exists($x, …)` guard or an `instanceof` narrowing of `$x` no longer survives the rebind and prunes code that runs.** The alias assignment kept the old binding's guards and narrowed class, while every other assignment dropped them. Findings can appear in code that was wrongly folded dead after such a rebind (for example an argument finding inside `if ($ok)` after `$ok = method_exists($x, 'm'); $x = $y;`), and `PHPStan\dumpType($x)` after the rebind now shows the new object's class.
