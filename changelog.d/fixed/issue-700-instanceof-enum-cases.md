- **An `instanceof` guard over an enum-typed parameter no longer empties it.** `function f(Suit $s) { if ($s instanceof Suit) { … } }` read `$s` as `*NEVER*` inside the branch, and so did `Suit|string|null`, `Suit|int` and `instanceof \UnitEnum`, because each of the enum's cases was judged as if it were not an object. A case is now judged by its enum: it is an instance of the enum, of `UnitEnum`, of `BackedEnum` when the enum is backed and of the interfaces the enum declares, so the guard keeps every case, and `!($s instanceof Suit)` now removes them (`Suit|string` reads `string` there). `\PHPStan\dumpType()` output changes inside such branches. No finding appeared from the emptied branch, since the consumers that read it stayed silent there, so no finding should appear or disappear.
