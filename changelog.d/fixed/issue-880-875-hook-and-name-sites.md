- **A body that builds an object whose property hook runs, converts an object through a dynamic name, or stores an object into a string by offset is no longer read as complete.** Four more places can run your code and were read as running none: a promoted constructor parameter with a `set` hook (`__construct(public string $p { set { … } })` runs the hook at promotion, so the constructor itself is now `…?` and so is every `new` of it); a project class that hooks a property and extends an engine class, including a hook on `$line` or `$file` that runs at creation whatever constructor the class has (`class E extends RuntimeException { protected $message { set { … } } }`: `new E('x')`, `parent::__construct(…)` in it and, in the effect lane, `getMessage()` on it or on a `Throwable` parameter when such a class exists in the project all run the hook); a name the engine converts to a string (`$o->$n`, `$$n`, `P::$$n`, with `$n` an object that may have `__toString`); and the value of an offset write into a container that may be a string (`$s[0] = $o` and `$s[0] ??= $o` convert `$o`). A container is known not to be a string when it is a parameter declared `array` or a class, a local only ever assigned arrays, `null`, numbers, booleans or objects, or `$this->p` declared with such a type; an append `$c[] = $v` is never a conversion. A name or value that is an exact class with `__toString` is an edge to it, so its effects and throws reach the caller, and an exact class without one runs nothing. The kinds are the existing `operator-to-string` and `operator-magic-property` in `annotate --format json` and the effect baseline. Functions that read `…?` can lose their `effects-envelope` rewrites, and `throw.maybe-undeclared` appears at `strict` on more sites (68 on the ten public corpus packages, 65 of them at `$c[k] = v` with a container that is a local assigned from a call, an element or an untyped property); no body that was complete becomes `…?` there, no `effects-envelope`, `throws-envelope` or `loop-to-array-map` plan changes, and `effect-diff` reports nothing. A frame that reads a variable variable (`$$n`) shows no name of its own, so even a `string $n` there is a gap.
