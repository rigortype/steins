- **`method_exists(C::class, 'm')` on an abstract class or an interface now counts a method `C` declares only through an interface it implements or extends, so the body it guards is no longer read as dead.** PHP's `method_exists` is true there (an interface's abstract method is the class's own), but Steins walked only the `extends` chain, missed every implemented interface and every parent of an interface past its first, and folded the guard false. Findings can appear inside such a body, which Steins used to skip. An abstract class or interface that implements an interface Steins cannot enumerate (a builtin such as `\Countable`, a vendor name) now leaves the guard undecided instead of folding it false.
