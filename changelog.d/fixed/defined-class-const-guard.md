- **`defined('C::K')` now guards the class-constant checks, so `if (defined('A::K')) { … A::K … }` no longer reports a false `class-const.undefined` or `class-const.inaccessible`.** The call folds against the constant's reach and the calling scope's visibility, as PHP answers it: false for an absent constant or one the scope cannot access, true for a public constant, an enum case or an interface constant. Findings disappear inside a branch the guard proves dead, and code after `if (!defined('A::K')) { return; }` is read as dead when `K` is absent or inaccessible; `self::`, `static::` and `parent::` spellings still do not fold.
