- **A call or member use in top-level code above a class PHP does not bind early is no longer judged against that class, and a use of a conditionally declared function or class now says it may be undefined.** `new X()` above `class X implements I {}` (or `extends` a later or missing parent, `use T`, an `enum`), and `f()` above `if (…) { function f() {} }`, raise "Class not found" / "Call to undefined function" on PHP, so `call.too-few-arguments`, `call.unknown-named-argument`, `call.undefined-method`, `class-const.undefined`, `call.inaccessible-method` and `class-const.inaccessible` stay silent there; a plain top-level class, one extending an earlier class or an engine class, and every unconditional function are hoisted and still judged, and a use inside a function, method or closure body is judged as before, since the body runs when called. Findings can disappear on such uses.
  - **A conditional declaration keeps its finding with a longer message.** `if (false) { function f(int $a) {} } f();` still reports `call.too-few-arguments`, now ending with `or Error "Call to undefined function" if its conditional declaration has not run` (`Class not found` for a class hierarchy), so a suppression keyed on the id no longer hides which error PHP raises.
