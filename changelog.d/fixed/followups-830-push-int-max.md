- **`$a[] = …` and `array_push()` now name the key when the appended value lands on `9223372036854775807`.** `PHP_INT_MAX` is itself a key an append can take, so `$a = [9223372036854775806 => 1]; $a[] = 2;` builds `[9223372036854775806 => 1, 9223372036854775807 => 2]`, and `array_push()` with several values fills keys up to `PHP_INT_MAX` the same way. Steins gave up on the append whenever its last value landed there and typed `$a` as `non-empty-array{9223372036854775806: 1|2, ...<int, 2>}`; it now types it `array{9223372036854775806: 1, 9223372036854775807: 2}`. A value that would need a key past `PHP_INT_MAX`, where PHP throws, still names none. Findings that read those arrays can change with the type.
