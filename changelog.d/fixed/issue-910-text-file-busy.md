- **A `php` that is briefly busy to `exec` no longer turns the sidecar off.** Linux refuses to execute a file that another process still holds open for writing (`Text file busy`), which happens for a moment while an interpreter is rewritten in place, such as a version manager regenerating its `php` shim. The sidecar now retries a spawn refused that way up to five times over about 150 ms before reporting it, instead of treating the first refusal as a missing or broken engine.
