- **`throw.undeclared` no longer fires when `@throws` or `catch` names an interface the thrown exception implements.** Steins compared a thrown class with a declared or caught type by walking `extends` alone, so `@throws DomainError` over `throw new Oops()`, where `Oops extends RuntimeException implements DomainError`, was reported as an undeclared escape, and `catch (DomainError $e)` was treated as letting `Oops` through to the caller. Interfaces an ancestor implements, and interfaces an interface extends, count as well. `throw.liskov-widened` uses the same check, and `steins transform throws-envelope` no longer writes a `@throws` tag that an interface already in the docblock covers.
  - Engine exceptions now resolve through the full builtin class hierarchy rather than a fixed list of SPL classes. An engine exception the list lacked, such as `PDOException` or `ReflectionException`, used to be treated as unknown and silent; it is now checked, so `throw.undeclared` can fire for it.
  - An interface no analyzed file declares (a vendor interface outside the analysis) could extend anything, so a `@throws` or `catch` naming another interface stays silent past it. It cannot make a class a subtype of another class, so a class in `@throws` is still decided as before.
