blanket demotion. Two of the original four were answered empirically

Answered 2026-07-24 (verified `php -r` on PHP 8.5.8, orchestrator):

- **Compound-assignment read-half**: `$a[0]++`, `$a[0] .= "x"`, and
  `$a[0] += 5` on a missing key ALL emit `Warning: Undefined array
  key 0` (the read half fires; the write half then creates the key).
  `$a[0] ??= 5` is SILENT (isset semantics). Consequence for the §7/A7
  whitelist: compound assignments are read-context **eligible**;
  `??=` joins the isset-family silence leg.
- **Include precedence**: a bare relative literal (`include
  "target.php"`) resolves include_path → calling script's directory →
  CWD, in that order (all three positions verified by elimination).
  A `./`-prefixed literal (`include "./target.php"`) resolves against
  **CWD, not the script directory**. Consequence: the A5 wording
  ("only absolute and `__DIR__`-anchored literals are provable") is
  exactly right — `./` prefixing does NOT anchor to the including
  file, so `./`-literals stay Unproven dam sites; any future
  `[runtime] include-path` refinement must model the three-step order,
  and directory-relative belief (the pre-amendment `resolve_from`
  behavior) is wrong in both directions.

### ADR-0057 Returned-allocation heap transfer — 2026-07-24

Thrust: close the measured boundary gap (owner probes — a factory's
heap allocation dies at the return: `createFoo(123)->n` can never be
`123`; DTO pipelines widen at the first boundary) by carrying a
**return-object summary** out of the binding descent and rebinding it
as a fresh allocation in the caller's heap — copy semantics, no shared
identity. The ADR-0048 §2 argument decides the mechanism: a summary is
a pure function of (callee CST, bound entry state, query answers) — a
legitimate query answer; allocation-id threading is a live pointer
into an ended walk (cross-scope mutable coupling + ordering
dependence) and is refused.

Key decisions: snapshot per return site (class, class_exact, props
with strata, readonly set, escaped-before-return — taken post-sweep,
pre-return-escape-marking); multiple paths JOIN (per-prop fact join
with strata min, all-paths presence, exactness only under class
agreement); differing classes or any non-allocation path ⇒ NO summary
(widen to the declared-return arm floor — silence over guess, never a
partial lie); origin-independent soundness (a summary of the walk's
knowledge is sound for param-origin objects too) with A1 exactness

descent memo upgraded from suppression set to value map (BindingKey →
Option<Summary>, cacheable because the key determines the entry

extension (name-keyed sorted binding); zero-arg factories get an
emission-suppressed summary-only walk memoized under the empty key
(discarding duplicate findings is dedup, not silencing); `new` stated

objects-in-arrays (the array_map composition — NEXT adjacent, on

annotate margins + a new object-return fixture family; nsrt is thin
